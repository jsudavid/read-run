# 云端探险

第三个场景采用 3D 声控热气球，入口为“云端探险”，快捷键为 `3`。
暂停、重置、灵敏度、画质、今日主角照片和视角控制使用现有游戏宿主。

## 规则

- 声量强度达到 0.5 并保持 0.35 秒后才提供升力，过滤短促尖峰。
- 升力与速度由持续达标时间决定；达标后的更高音量不会额外加速。
- 换气宽限为 1.2 秒，短暂换气保持高度；持续安静会以约每秒 1.4 米缓缓下降，停靠后可再次朗读起航。
- 高度上限 32 米，升速上限每秒 2.8 米，航速上限每秒 7 米。
- 航线每 35 米出现一颗星星，经过时达标且高度至少 8 米即可收集；接近时星星向吊篮靠拢。
- 每 160 米点亮一个航段。降落保留星星、航段和累计航程；重置或切换场景开始新一轮，与现有宿主一致。
- 暂停冻结高度、时间和全部奖励，仍可调整镜头和环境。

## 实现与验证

`web/src/balloon/flight.js` 只处理声音到飞行、奖励的映射。
`web/src/balloon/mode.js` 独立构建热气球、云海、星星与航线驿站，使用现有 Three.js 和 `SceneView`，无新增依赖。
前两款游戏的模拟模块与音频采集链路保持原实现。

`npm test` 包含起航、尖峰过滤、持续朗读、换气、降落、奖励保留和重置检查。
开发页面 `/tests/camera.html?quality=mid` 对三种模式执行真实 WebGL 回归。

玩法参考 [VOICE-CONTROL-REFERENCE.md](VOICE-CONTROL-REFERENCE.md) 中 Sparkler Game 的持续推力与 Chinese Flying Sound Run 的持续飞行思路；本场景独立实现，无语音识别、音调识别或外部项目代码移植。
