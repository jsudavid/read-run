# 3D 视角与场景控制

运行 `npm run dev`，点击开始后，右上角相机按钮（快捷键 `C`）打开控制区。

- 画布左键拖动 / 单指滑动：自由环绕；滚轮 / 双指缩放：拉近或拉远；右键拖动 / 双指平移：移动焦点。
- 选择机位：自动跟拍、电影运镜、侧拍、迎面、后方追随、全景、俯瞰；鹈鹕额外支持第一视角。
- 拖动画布或操作距离、视场角时，进入自由模式，自动镜头不会覆盖操作。恢复按钮回到自动跟拍。
- 三个游戏分别保留本次会话中的机位和环境设置。重置只清空游戏进度，刷新页面后恢复默认设置。
- 鹈鹕支持时间、昼夜速度、云量、海浪、雾、曝光、泛光、头盔、围巾、墨镜；追赶支持随朗读破晓或手动天色、雾、曝光、泛光。
- 云端探险支持侧面伴飞、迎面飞行、云海全景、俯瞰航线，以及自动跟拍、电影运镜和自由环绕；环境支持云量、雾、曝光、泛光。
- 画质设置共用自动 / 低 / 中 / 高；低画质不使用泛光，对应滑块禁用。

## 来源

鹈鹕相机与八段电影序列来自
[pelican-bike/src/main.js](https://github.com/riba2534/claude-opus-5-5-demo/blob/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8/pelican-bike/src/main.js)。
手动控制使用当前 Three.js 自带的 `OrbitControls`，没有增加依赖。
追赶模式机位与电影镜头根据本项目的主角、狼群及地形重新取景。
声音驱动的速度、进度与追赶规则仍由原有模块负责。

## 验证

`npm test` 检查相机控制接管、缩放边界、焦点跟随、状态恢复与事件释放。
开发服务上的 `/tests/camera.html?quality=mid` 是实际 WebGL 冒烟页：
逐一渲染三种模式的机位，检测姿态、画布像素、模式恢复和重置。
该页面不进入生产构建。
